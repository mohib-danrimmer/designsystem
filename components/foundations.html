Every gap and padding in the system is a multiple of 8px. The two cards below are structurally identical — only the spacing tokens differ, producing a compact listing density and a comfortable featured density.

How to read this Indigo strips = padding (space between card edge and content). Amber strips = gaps between sections. Each strip is labelled with the token and its px value. The background grid lines mark every 8px — notice every strip snaps exactly to the grid.

Concentric Radius — Box Inside a Box

The Rule
inner radius = outer radius − gap
When one rounded element sits inside another, the inner element's radius must be smaller — exactly equal to the outer radius minus the distance between them. This keeps both arcs concentric (sharing the same centre point), so the corridor between them looks like a uniform band all the way around. If the inner radius is too large, the corners balloon outward and the gap widens at every corner. If the inner radius is too small or sharp, the inner corners look pointed and detached.
Wrong — inner radius too large
inner: --radius-2xl · 16px ✗
outer: --radius-2xl · 16px
Gap: --space-3 (12px) · Inner uses the same 16px radius as the outer. The inner corners arc too far — they no longer share a centre point with the outer corners. The corridor is thin at the sides but balloons wider at each corner.
Right — inner radius = outer − gap
inner: --radius-sm · 4px ✓
outer: --radius-2xl · 16px
16 − 12 = 4px → --radius-sm · Both arcs share the same centre point. The 12px corridor is exactly the same thickness everywhere — straight edges and around every corner.
Three Levels Deep — Product Card
